# SilenceDiors's Blog

Personal blog powered by Jekyll and GitHub Pages.

## Local Development

```bash
# Install dependencies
bundle install

# Start local server
bundle exec jekyll serve

# Visit http://localhost:4000
```

## Writing Posts

Create new posts in `_posts/` directory with the format:
`YYYY-MM-DD-title.md`
